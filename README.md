# 📋 Sistema de Cadastro de Clientes

## 📖 Descrição

Este projeto foi desenvolvido como atividade prática de Desenvolvimento Web, com o objetivo de criar uma interface para cadastro e gerenciamento de clientes utilizando HTML, CSS e JavaScript.

A aplicação permite cadastrar, visualizar, pesquisar e excluir clientes por meio de uma interface responsiva e intuitiva.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## ✅ Funcionalidades

- Cadastro de clientes
- Listagem de clientes cadastrados
- Pesquisa de clientes em tempo real
- Exclusão de clientes
- Validação de campos obrigatórios
- Máscara automática para CPF
- Máscara automática para telefone
- Interface responsiva para dispositivos móveis
- Contador de clientes cadastrados

## 👨‍💻 Campos do Cadastro

O formulário possui os seguintes campos:

- Nome
- E-mail
- CPF
- Telefone

### Formatação Automática

**CPF**

```text
000.000.000-00
```

**Telefone**

```text
(00) 00000-0000
```
